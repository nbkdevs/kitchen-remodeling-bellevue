## Full description (plain text)

```
Kitchen Remodeling Cost Planner splits a kitchen remodel budget into 12 line items (cabinets, installation and labor, appliances, countertops and backsplash, flooring, lighting, painting and drywall, designer, sink and faucet, doors and windows, plumbing, miscellaneous) and adds sales tax, a contingency reserve and a permit allowance.

Two modes:
- Split a budget: enter the all-in amount you can spend and see what is left for construction after tax, reserve and permits.
- Estimate from cost: enter a contractor's construction price and see the real total with reserve, sales tax and permits on top.

Cost vs Value presets load a minor midrange, major midrange or major upscale kitchen remodel (Pacific region averages, 200 sq ft kitchen). All arithmetic is done in integer cents with largest-remainder rounding, so every line adds up to the exact total.

Downloads:
- kitchen-remodeling-cost-planner-web-1.0.0.zip: offline web calculator. Unzip and open index.html in any browser. No install, no network calls, no tracking.
- kitchen-remodeling-cost-planner-1.0.0.vsix: VS Code extension with a planner panel and a command that inserts the cost breakdown as a Markdown table.

The same calculator is available as libraries for JavaScript (npm kitchen-remodeling-cost), Python, Rust, Dart, .NET, Ruby and PHP.

Homepage: https://wakitchenremodelingbellevue.com/
Source code: https://github.com/nbkdevs/kitchen-remodeling-bellevue
License: MIT
```
