# Packagist: manual step

No Packagist API token is set up, so the package is not on Packagist yet.

1. Sign in at https://packagist.org.
2. Open https://packagist.org/packages/submit and paste `https://github.com/nbkdevs/kitchen-remodeling-bellevue`. The root `composer.json` names the package `bellevuekitchenpros/kitchen-remodeling-cost`.
3. Add the GitHub webhook (Packagist profile > API token > GitHub hook) so tags update automatically. The `v1.0.0` tag is the first release.
